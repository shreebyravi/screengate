# ScreenGate: Design notes

The page's colours and fonts live in `index.html`.

- **Style:** a calm, dark operations console for reviewing one payment at a time.
- **Labels:** plain language instead of compliance or technical terms, such as Looks clear, Extra checks needed and Cannot clear: escalate.
- **Phone layout:** one payment at a time, with Back buttons.
- **Status:** colour is never the only signal; text labels always go with it.
