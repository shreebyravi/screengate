# ScreenGate: Roadmap

## This prototype: prove the loop

- Flag, check, recommend and a person's decision, on two corridors
- Cited evidence and hard escalation rules
- Six tests and one documented improvement
- Recorded examples anyone can try

## Next scope: make a pilot possible

- As a head of compliance, I set payment ceilings by risk level.
- As a compliance officer, I require a second approver for very large payments.
- As an analyst, I sort and filter the queue.
- As an analyst, I give feedback inside the product.
- As an auditor, I can see saved decisions and evidence.
- As a product owner, I measure a baseline and can re-run evals after each change.
- As a compliance officer, I know a shared ID or birth date can't be cleared by one different field, because the policy and code both stop it.

## The scope after that: make it work with real systems

These are proposals, not commitments.

- As a company, I connect the payment system and a trusted watchlist.
- As an analyst, I can review names in other languages and spellings, using a dedicated matching step.
- As a compliance team, I add corridors only after evidence from the first two.
- As a buyer, I compare build and buy using the same test set.

## Staying out of scope

Fraud detection, customer due diligence and regulatory reporting remain separate unless evidence supports a change.

## What would change this plan

- Analysts say review time or consistency isn't the real problem.
- Existing vendor tools already meet the need.
- Tests show missed escalations.
